# Bioinformatics Toolkit

A collection of practical Python tools for bioinformatics, computational biology, and genomics. This repository contains lightweight utilities designed to automate common analysis tasks, visualise biological data, and support research workflows.

The aim of this project is to build an open-source toolkit of reusable bioinformatics utilities while continually expanding my experience across genomics, transcriptomics, proteomics, cancer biology, and machine learning.

---

## Features

The toolkit currently includes (or will include) utilities for:

### Genomics

* Variant filtering
* SNP frequency analysis
* GWAS Manhattan plots
* QQ plots
* Mutation spectrum analysis
* Cancer mutation dashboards
* Chromosome mutation visualisation
* Copy number alteration plotting

### Transcriptomics

* RNA-seq quality control
* Principal Component Analysis (PCA)
* Volcano plots
* MA plots
* Gene expression heatmaps
* Expression lookup tools
* Sample quality reports

### DNA & Sequence Analysis

* FASTA statistics
* GC content analysis
* Open Reading Frame (ORF) detection
* Reverse complement generation
* Restriction enzyme site identification
* Codon usage analysis
* Primer quality checks

### Proteomics

* Protein property calculators
* Amino acid composition analysis
* Protein mutation mapping
* Conserved residue identification
* Sequence logo generation

### Functional Analysis

* Gene Ontology (GO) visualisation
* KEGG pathway summaries
* Gene list comparison
* Biomarker ranking

### Machine Learning

* Cancer classification
* Mutation prediction
* Feature importance analysis
* Dimensionality reduction tools

### Clinical Bioinformatics

* Kaplan–Meier survival analysis
* Clinical dataset validation
* Patient mutation summaries

### Utilities

* Bioinformatics file validation
* Metadata merging
* Publication-quality plotting
* Multi-omics dataset inspection

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/Bioinformatics-Toolkit.git
cd Bioinformatics-Toolkit
```

Install the required packages:

```bash
pip install -r requirements.txt
```
